# 世界线（会话树：分叉与回退）

会话不是一条线，而是一棵树。同一句用户消息下可以有多个助手回复，同一段历史
可以从任意一点重新开始——每条从根到叶的路径就是一条**世界线**。

这个概念直接借自《命运石之门》：时间跳跃会产生新的世界线，旧世界线依然存在，
"阅读斯坦纳"让人保留跨世界线的记忆。本项目里的对应关系：

| 作品 | 本项目 |
| --- | --- |
| 世界线 | 会话树里从根到某个叶子的一条路径 |
| 世界线分叉 | 同一父节点下的第二个子节点（重新生成 / 回退后重说） |
| 世界线跳跃 | 把活动叶切到另一条路径（消息旁的 `‹ 2/3 ›`、标题栏世界线面板） |
| 时间跳跃 / 回退 | 把活动叶退回到中途某个节点，从那里重新开始 |
| 世界线变动率 | 标题栏展示值：由当前末端 id 稳定推导，1.000000 ~ 1.999999% |
| 阅读斯坦纳 | 长期记忆按用户存储，跨世界线保留（对话摘要不跨） |

## 1. 数据模型

```
messages
  id            消息 id
  session_id    所属会话
  parent_id     父消息 id（根消息为 NULL）——树的边
  role/content/tts_text/mode/created_at

sessions
  active_message_id  当前活动世界线的末端（可以是叶子，也可以是回退到中途的节点）
```

- **活动世界线** = 从 `active_message_id` 沿 `parent_id` 回溯到根的那条路径。
  读取会话、组装 LLM 上下文、压缩，全都只看这条路径。
- **叶子** = 没有子节点的消息。叶子数 = 世界线总数。
- **兄弟** = 同一 `parent_id` 下的所有消息。兄弟数 > 1 处就是分叉点。

老库迁移：`db.init()` 检测到 `messages` 缺 `parent_id` 时 `ALTER TABLE` 并回填
（每条消息的父节点 = 同会话时间上紧邻的前一条），同时把每个会话的
`active_message_id` 指向最后一条消息。迁移只在列首次出现时执行一次。

## 2. 运行时路径

| 操作 | 数据变化 |
| --- | --- |
| 发消息 | 新用户消息 `parent_id = 当前 active`，`active` 前移到它；回复落库后 `parent_id = 用户消息`，`active` 再前移 |
| 重新生成 | `active` 退回到产生旧回复的那条用户消息 → 新回复成为它的**第二个子节点**；旧回复留在树上成为兄弟（不删除） |
| 世界线跳跃（`‹ 2/3 ›` / 面板） | `active` 设为目标支路的**最新叶子**（`latestLeafUnder`） |
| 回退（消息上的「回到这条世界线」） | `active` 精确设到该消息；之后发消息会从这里分叉 |
| 跳线 / 回退 / 重新生成 | 清掉本会话的压缩摘要（摘要属于跳转前那条世界线） |

接口（brain）：

- `GET /api/sessions/:id/messages` → `{ messages, worldline }`，消息上带 `siblingIds`
- `POST /api/sessions/:id/head` `{ messageId, toLeaf }` → 跳转后的同一个消息页
- `GET /api/sessions/:id/worldlines` → 每条世界线的序号 / 变动率 / 末句预览 / 是否当前

## 3. 不能违反的约束

1. **不删消息。** 分叉、回退、重新生成都不删除任何历史——旧内容只是不在当前
   世界线上，随时可以跳回去。删除只有用户显式删会话。
2. **只读活动路径。** 上下文组装（含压缩）只走 `listMessages`（活动路径），
   绝不能把整棵树塞给模型。
3. **跳线不动 `updated_at`。** 跳世界线不是新的对话活动，不该把会话顶到列表最前。
4. **跳线清摘要。** 摘要描述的是某一条世界线的历史；换了世界线还沿用旧摘要，
   模型会记住没发生过的事。跨世界线保留的只有按用户存储的长期记忆。
5. **迁移只做一次。** 回填只在 `parent_id` 列不存在时执行；重复执行会覆盖用户
   已经形成的分支结构。
6. **回合进行中不允许跳线。** 流只属于当前世界线，跳走会让新内容落到看不见的分支上。

## 4. UI

| 位置 | 行为 |
| --- | --- |
| 消息元信息行 `‹ 2/3 ›` | 该消息有兄弟时出现，左右切换世界线（跳到该支路最新状态） |
| 消息操作「回到这条世界线」 | 不在末端的消息可点，回退到它（`rewound` 状态） |
| 标题栏徽标 | `世界线 n/m · 1.048596%`；回退中会标「回退中」 |
| 标题栏面板 | 世界线列表（序号、变动率、末句预览、当前标记），点一下跳过去 |

## 5. 怎么验证

```bash
# 无需真实 LLM / 无需桌面端：假 LLM + 临时库 + 独立 brain 子进程
node scripts/e2e-worldline.mjs
```

覆盖：线性对话成链；重新生成产生兄弟（旧回复不丢）；世界线跳跃切回旧版本；
回退后重说分叉出第三条世界线；世界线列表的序号/变动率/预览/当前标记；
跳线清摘要；**老库迁移**（旧 schema 启动后自动回填成一条链）。

自证"缺了会挂"：把 `appendMessage` 里的 `parentId` 固定成 `null` → A/B/C/D/E 全红；
把 `setActiveMessage` 改成空实现 → A/B/C/D/E 全红。恢复后全绿。
