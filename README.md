# pi-amadeus
基于Pi Agent二次开发的Amadeus，旨在打造一个综合的个人助手

## 隐私

- 会话、消息、记忆与配置都存在本机大脑服务的 SQLite 文件里。
- 摄像头视觉输入与「后台主动问候」的桌面截图只发给**你自己配置的模型服务**，
  用于当次识别：不保存到磁盘、不写日志、不回显。主动问候可在
  设置 → 通用 →「后台主动问候」随时关闭；关闭后不再截屏、不再请求。
- 没有遥测上报。
